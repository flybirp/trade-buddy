# 交易命题、催化剂与同业比选

## 一句话交易命题

完成取数后必须收敛为：

> 买入这只股票，本质是在押注 ______ 在 ______ 时间内尚未被充分定价。

命题应可证伪。禁止“受益于行业发展”“可能有资金关注”这类空话。

## 用户非共识假设审计

用户可能掌握通用数据源没有覆盖的产业细节、渠道变化、产品体验、地方政策、供应链观察或认知差。这类线索是潜在超额收益来源，不能被常规模型粗暴过滤；但用户也可能受到确认偏差或信息误传影响，所以必须把“观点”转成“可证伪假设”。

### 1. 结构化用户线索

记录五项：

| 字段 | 内容 |
|---|---|
| 用户原话 | 不改写地保留 |
| 可检验命题 | 如果为真，应看到什么结果 |
| 传导链 | 事件 → 行业 → 公司业务 → 财务/估值 → 股价 |
| 时间窗口 | 何时应出现证据 |
| 证伪条件 | 什么出现代表判断错了 |

### 2. 分层检索

按“离事实最近”原则依次查：

1. 交易所/公司公告、监管文件、政府或行业协会原文
2. 公司回应、调研纪要、产品页面、招投标、客户/供应商披露
3. 行业数据、价格/产量/订单/渠道等可观测代理变量
4. 券商研报与权威媒体
5. 社区、产业人士帖子和用户提供材料，只作线索，不直接升格为事实

通用检索无结果不等于假设为假。先判断是“数据源覆盖不到”“尚未公开”“关键词不对”，还是“确实不存在”。

### 3. 四层审计

- **事实**：事情有没有发生？
- **归因**：目标公司是否真正受益，受益比例多大？
- **定价**：市场什么时候知道，价格是否已经反应？
- **反证**：有没有更强的替代解释？最有力的空头证据是什么？

### 4. 状态机

`用户线索 → 待验证 → 部分支持 / 已证实 / 已证伪 → 未定价 / 定价中 / 已充分定价`

只有“已证实且未充分定价”的线索可以进入核心交易命题并调整概率。部分支持的线索只进入观察清单；待验证线索不得提高仓位。后续新证据出现时更新状态，而不是重新讲故事。

## 催化剂评级

从五个维度判断：

1. **真实性**：公告/政策原文 > 公司回应 > 权威媒体 > 市场传闻
2. **新鲜度**：首次增量 > 旧信息强化 > 老调重弹
3. **业绩传导**：能否说明影响收入、利润、现金流或估值；只有概念映射则降级
4. **持续性**：多季度产业趋势 > 阶段性事件 > 一日新闻
5. **定价程度**：价格尚未反应 > 分歧中反应 > 已连续加速充分定价

输出：强 / 中 / 弱 / 噪音，并写出上调与下调的证据。公告标题不能自动等于利好。

## 行业景气度

回答四件事：

- 行业处于导入、成长、成熟还是下行阶段
- 需求、供给、价格和政策的边际方向
- 板块指数与主要成分股是否同步验证
- 景气变化何时能传导到目标公司的收入/利润

无法建立“行业变化 → 公司业务 → 财务结果”链条时，不把行业叙事计入交易命题。

## A股稀有性

稀有性必须基于真实业务而非概念标签：

- A股内纯正同类业务公司数量
- 该业务占目标公司营收/利润比例
- 是否拥有独占牌照、渠道、IP、客户、资源或技术
- 稀缺是否能转化为更高盈利或更强资金辨识度

“题材唯一”但业务贡献极低，只能算情绪加分，不能算基本面护城河。

## 同业与龙头判断

先建立真正可比的3–5家公司，再用同一口径比较：

- 业务纯度与市场份额
- 营收规模和增速
- 盈利能力与现金流
- 市值与估值
- 近阶段股价强度、成交额与资金辨识度
- 催化剂强度与兑现时点

分别给出：

- 产业龙头
- 业绩龙头
- 短线情绪龙头
- 弹性标的

它们可能不是同一家公司，不能笼统称“龙头”。

## 是否建议换标的

只有满足以下任一条件才建议替换：

- 原标的业务纯度明显更低且没有估值补偿
- 原标的催化已兑现，而同业存在更清晰的未定价催化
- 原标的技术位置明显更差，替代标的赔率更好
- 原标的是后排跟风，主线龙头仍有可交易性

输出统一比较表，并明确：

- 原标的保留理由
- 替代标的优势
- 替代标的新增风险
- 最终倾向：保留 / 换标的 / 暂不做该赛道

不能因为“不是龙头”就机械换票；龙头可能估值过高，二线股可能拥有更好的预期差。
