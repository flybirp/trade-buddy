# 条件式交易执行方案

## 原则

输出的是预案，不是盘前猜明天涨跌。每个动作必须绑定条件；条件不满足就不执行。

## 先判断位置

- 低位启动：长期下跌后横盘，放量突破
- 趋势中继：上升趋势中缩量回踩
- 高位加速：连续上涨、远离短期均线、放量
- 高位震荡：高位横盘、高换手、方向未明
- 下跌反抽：下降趋势中的反弹
- 触板炸板：最高触及涨停附近但收盘明显回落，放量上影

## 次日情景树

至少覆盖：

| 开盘/盘中情形 | 必须判断 | 动作类型 |
|---|---|---|
| 高开 | 是否透支、是否有板块共振、回落承接 | 等回踩 / 放弃追价 |
| 平开 | 是否站稳关键位、量能是否确认 | 试错仓 / 等确认 |
| 低开 | 是否守住支撑、是否快速修复 | 轻仓试错 / 取消交易 |
| 放量突破 | 真突破还是冲高回落 | 确认仓 |
| 跌破失效位 | 催化与结构是否证伪 | 取消或止损 |

## 分仓设计

默认三段：

1. 试错仓：总计划仓位的20%–30%
2. 确认仓：30%–40%
3. 加强仓：剩余部分，仅在逻辑和走势同时强化时执行

总仓位由风险反推：

> 可承受仓位 ≈ 单笔风险预算 ÷ 止损距离

止损距离越大，仓位越小。没有失效位就不计算仓位。

## 止损

优先级：

1. 交易逻辑失效
2. 关键结构位破坏
3. 成本百分比保护
4. 时间止损

止损必须结合实际成交成本。禁止仅锚定昨日开盘价等历史价格，导致次日高低开时风险敞口失控。

## 止盈

- 达到第一目标时分批回收风险
- 达到目标价但量价继续强化，可保留小部分跟踪仓
- 放量滞涨、催化兑现、板块转弱时提前兑现
- 到达计划期限仍未完成目标，重新评估机会成本，不自动展期

## 触板炸板专项

如果前一日触及涨停但未封住：

- 次日明显高开不直接追
- 第一笔等待回踩关键支撑后出现承接
- 第二笔等待放量收复炸板回落区
- 再次冲板但封单/承接弱，视为抛压未消化
- 低开跌破支撑且板块无修复，取消交易
