# 港股 / 港股通适配

标的为 `hk` 前缀时，先读本文件。目标是**不把 A 股的分析框架硬套到港股上**——两者在交易机制、数据源、成本结构上差异巨大。

---

## 1. 能力矩阵（westock-data 实测，2026-09-01 验证）

| 分时 | `minute hk00700 --days 5` | ✅ | ✅ | |

## 2. 港股通可交易性校验（动手前的第一件事）

**不是所有港股都能通过港股通买。** 标的范围由沪深交易所定期调整：

- 恒生综合大型股指数、中型股指数成份股
- 恒生综合小型股指数成份股（市值达标，门槛约 50 亿港元）
- A+H 股公司在联交所上市的 H 股
- 符合条件的在港主要上市外国公司（2022 年 12 月扩容纳入）
- **排除**：以港币以外货币报价的；同时在上交所以外内地交易所上市的；A 股为风险警示板的 A+H 股

**校验方法（按优先级）**：

1. **用 `hkfund` 反查（快，L1 级信号）**：能返回 `_lgtHoldInfo.LgtHoldRatio` 且 > 0，说明当前有港股通持仓 → 大概率是港股通标的。实测：腾讯 11.81%、阿里 10.08%、汇丰 8.93%、港交所 3.49%。
2. **GEM 股票（8 开头代码）返回「数据为空」** → 不在港股通。实测 `hkfund hk08083`（有赞科技）返回空。
3. **权威名单以交易所公告为准**：
   - 深交所：https://www.szse.cn/szhk/hkbussiness/ （港股通业务信息 → 标的证券名单）
   - 上交所：https://www.sse.org.cn/
   - 名单季度定期检讨 + 不定期调整，**须核对最近一次调整公告的生效日**

**写进决策单**：标的确认在名单内 → 标注最新一次调整公告日期与生效日；若拿不到公告原文，标 L2 并列入数据缺口。

## 3. 交易机制差异（直接改写情景树）

| 维度 | A 股 | 港股通 |
|---|---|---|
| 回转 | T+1 | **T+0**（当日买入可当日卖出，次数不限） |
| 交收 | T+1 | **T+2**；T 日卖出资金 T 日可再买港股、T+2 可买 A 股、T+3 可银证转出 |
| 涨跌幅 | ±10%/20% | **无涨跌停**，但有市调机制与收市竞价价格限制 |
| 每手股数 | 统一 100 股 | **公司自定**（腾讯 100 股/手、汇丰 400 股/手）→ 必须查，影响最小建仓金额 |
| 交易日 | 沪深日历 | **两地均为交易日 + 满足结算安排**；港股半日市（圣诞/元旦/农历新年前一日）只有上午 |
| 额度 | 无 | 有每日额度（深港通下 105 亿元人民币），极端行情可能受限 |
| 融资融券 | 支持 | **不支持** |
| 新股申购 | 支持 | **不支持** |
| 交易时段 | 9:30–11:30 / 13:00–15:00 | 开市前 9:00–9:30（港股通仅 9:00–9:15 可用竞价限价盘）；持续交易 9:30–12:00、13:00–16:00（**12:00–13:00 港股通不能参与**）；收市竞价 16:00–16:06 |

**对情景树的改写要求**：

- A 股的「次日情景树（高开/平开/低开）」在港股通改为**「当日情景树」**——T+0 意味着开仓后当天就能了结，不必隔夜承担跳空风险。
- **删除所有依赖涨跌停的字段**：炸板率、连板高度、封单强度、隔日溢价，这些在港股不存在。原 skill 中「触板炸板专项」对港股**完全不适用**。
- 情景树改为覆盖：**开市前时段竞价方向 → 早盘突破/回落 → 午盘（13:00）重启 → 收市竞价 16:00–16:06 异动**。
- 止损必须写可执行性：港股无涨跌停且支持 T+0，止损位应设**条件单**而非依赖盘中止盈（港股的增强限价盘最多可挂较市价 24 个价位）。
- 交易日历必须单独校验：**A 股休市或港股休市，港股通都不能交易**。

## 4. 市值自算（profile 无 regCapital）

港股 `profile` 不返回 `regCapital`，用财报反推：

```
股本 ≈ ProfitToShareholders ÷ BasicEPS     （取自 finance --type zhsy 同一报告期）
市值 = 股本 × 最新价
```

**交叉验证**：腾讯 2024-06-30 中期报告 `ProfitToShareholders` = 980.84 亿港元、`BasicEPS` = 10.5075 → 股本 93.34 亿股 × 442.60 = 4.13 万亿港元，与实际市值吻合。

**注意**：EPS 用加权平均股本，回购力度大的公司会高估/低估；须在数据缺口标注「市值为财报反推值，未经第二来源确认」。

## 5. 港股独有数据源：南下资金（A 股完全没有）

`hkfund` 返回的 `LgtHoldInfo` 是**港股通（南下）持股**数据，字段：

| 字段 | 含义 |
|---|---|
| `LgtHoldRatio` | 港股通持股占总股本比例 |
| `LgtHoldShares` | 港股通持股股数 |
| `LgtShareChgDaily` / `LgtCapChgDaily` | 日变动（股 / 港元） |
| `LgtShareChgQuarterly` / `LgtCapChgQuarterly` | 季变动 |

**这是港股通标的最重要的资金信号**，必须进关键事实表，观察：

- 持股比例处于历史什么位置（需自行取多日/多月数据比对）
- 日/季变动方向：持续净流入 vs 净流出
- 与股价走势是否背离（价涨但南下资金流出 → 内资在派发）

## 6. 港股通成本模型（必须计入目标收益）

综合费率约 **0.3%–0.5%**，远高于 A 股，短线频繁操作会被磨掉：

| 项目 | 标准 |
|---|---|
| 印花税 | 成交金额 0.1%，**双向**，取整到元（不足 1 元按 1 元） |
| 交易征费 | 0.0027%，双向 |
| 交易费 | 0.00565%，双向 |
| 交易系统使用费 | 约 0.5 港元/笔 |
| 证券组合费 | 持有市值年化 0.008% |
| 佣金 | 券商各异，通常有最低收费（常为 100 港元） |
| **汇率转换费** | 约 0.1%–0.3%（含参考汇率与结算汇率之差） |

**硬性要求**：

- 目标收益率计算必须**扣除双边成本**。若用户目标 +5%，佣金最低 100 港元在 1 万港元本金上就是 1%。
- **小资金建仓要按「手」反推最小可行金额**：每手股数 × 股价 ×（1 + 成本率），低于最低佣金门槛的方案直接判定不可执行。
- 汇率风险单列：港币报价、人民币交收，人民币兑港币波动直接改变实际收益。持有期越长影响越大，1 年期标的必须在风险项写明。

## 7. 港股通特有事件风险

1. **入通 / 出通事件**（强催化或强利空）
   - 华泰证券统计（2017-02 至今）：新纳入标的在「公告后→生效日」窗口期相对恒指超额收益中位数 **+1.8%**、均值 **+5.2%**；2025-02 窗口期中位数达 +5.5%
   - 被调出标的同期中位数 **-5.3%**、均值 **-7.5%**
   - **存在「抢跑行情」**：公告前资金提前博弈，公告后常「卖事实」（案例：卧安机器人 2026-03 入通预期兑现后暴跌近五成）
   - 调出后**只能卖不能买**——持仓标的若被调出，退出计划要提前
2. **「高纳低剔」夹心层风险**：市值在纳入/剔除门槛附近（约 30 亿港元）的公司，估值与流动性风险显著
3. **老千股**：合股、供股、低价配股掏空散户。低价股（尤其 <1 港元）必须查股本变动历史与配股记录
4. **流动性风险**：港股大量标的日成交额极低，冲击成本高。**必须核验日均成交额**，低于建仓金额 20 倍的原则上不建议参与
5. **无涨跌幅保护**：单日波动可能极大，止损位被跳空穿过的概率高于 A 股
6. **AH 溢价**：若标的在 A 股同步上市，查 AH 溢价率；通过港股通买 H 股须说明溢价是否构成安全边际
7. **双柜台**：部分标的有人民币柜台（代码带 `-R`，如 `hk80700`）。港股通可交易人民币柜台，报价与港币柜台存在差异，须确认你用的是哪个柜台

## 8. 财报口径差异

- 港股报表类型：`zhsy`（综合损益表）、`zcfz`（资产负债表）、`xjll`（现金流量表）
- 报告期：港股以**中期报告**（6 月 30 日）和**年度报告**（12 月 31 日）为主，部分公司发季报 → `ReportType` 字段会标注「第一季报 / 中期报告 / 年度报告」
- 货币：`CurrencyType` + `CurrencyUnit` 字段，常见港币/港元，部分中概股美元
- 分部收入：`MainOperIncomeProduct` / `MainOperIncomeRegion` 是内嵌 JSON，含各业务线占比，**可用于判断业务纯度**
- 会计口径：港股可用 IFRS 或 HKFRS，与 A 股 CAS 存在差异，跨市场对比（尤其 AH 股）须注明

| 位置 | 补充内容 |
|---|---|

## 10. 港股公告与补充数据源（外部检索路径）

`cninfo-stock-data` / `cninfo-filing-scraper` 只覆盖 A 股，港股必须走港交所渠道：

| 需求 | 入口 | 证据等级 |
|---|---|---|
| **上市公司公告 / 年报 / 中期报告** | 披露易 HKEXnews https://www.hkexnews.hk （上市公司公告 → 标题搜索 / 内容搜索 / 预先界定的文件） | **L1** |
| 公告板（备用） | http://hkexnews1.bulletinboard.hk/index.htm | L1 |
| **沪深港通持股纪录（港股通持股权威口径）** | HKEXnews → 股权披露 → **沪深港通持股纪录查询服务** | **L1**，用于交叉验证 `hkfund` 的 `LgtHoldInfo` |
| CCASS 持股分布 | HKEXnews → 股权披露 → 中央结算系统持股纪录查询服务 | L1 |
| 大股东权益及淡仓 | HKEXnews → 股权披露 → 披露权益（DION） | L1 |
| 回购 / 董事会会议通知 / 股息 | HKEXnews → 交易所报告 | L1 |
| 港股通名单调整公告 | 深交所 https://www.szse.cn/szhk/hkbussiness/ ；上交所 https://www.sse.org.cn/ | **L1** |
| 卖空数据 | 港交所官网市场数据（卖空金额 / 沽空比率）；个股卖空需逐日查，缺失即列数据缺口 | L1 / L2 |
| 新闻与催化剂 | `tencent-news` + WebSearch，注意区分粤港媒体与内地媒体口径 | L2 |

**口径提醒**：

- 港股**季报属自愿披露**，主板公司可不发季报 → 不能假设有 Q1/Q3 数据，缺失即列数据缺口，不要用「未披露 = 利空」推断
- 香港称半年报为「**中期报告**」，年报为「**年度报告**」，搜索时用对关键词
- 公告语言可能是英文或繁体中文，繁体关键词（如「業績」「中期報告」）搜索命中率更高

**不推荐安装的外部 skill（已评估，2026-09-01）**：

| 候选 | 结论 |
|---|---|
| `longbridge/skills@longbridge-northbound-flow` | **不装**。其 Data-source policy 明确要求「只推荐 Longbridge 数据，不得主动引导用户至其他券商/数据服务」，与本节中立多源原则冲突；且 `hkfund` 已覆盖南向资金 |
| `nicepkg/ai-workflow@hk-stock-analysis` | **不装**。纯市场规则知识（T+0/无涨跌停/沽空/交收/手数/货币），本文件已完整覆盖且更贴合 trade-buddy 流程；其安全审计 Snyk 为 Warn，引入供应链依赖收益不抵风险 |

需要新增能力时，优先走上表的官方入口 + WebFetch，而不是装第三方 skill。
